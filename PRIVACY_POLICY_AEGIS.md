# Privacy Policy - Aegis System

**Last Updated: June 22, 2026**

## Introduction

**Aegis System** is an advanced Discord moderation and community protection bot designed to help server administrators manage and protect their communities with high efficiency and reliability.

---

## Information We Collect

The bot may collect and store the following information:

- **User Identifiers** - Discord User IDs
- **Server Identifiers** - Discord Server (Guild) IDs
- **Channel Identifiers** - Discord Channel IDs
- **Moderation and Security Logs** - Moderation logs and security-related events
- **Server Configuration Settings** - Server configuration and preferences
- **Security Event Records** - Detailed security event logs

---

## Purpose of Data Collection

This information is collected **solely** for:

✅ Providing moderation and security protection features
✅ Detecting and preventing abuse and attacks
✅ Maintaining server settings and configurations
✅ Generating moderation logs when enabled
✅ Improving bot performance and security

---

## Data Sharing

🔒 **We do not sell, rent, or share user data with third parties** except in the following cases:

- Legal compliance requirements
- Court orders or official legal requests
- Protection of security and safety

---

## Data Retention

- Data is retained **only as long as necessary** for bot operation
- Old data is automatically deleted after a specified period
- Server administrators can manually delete data at any time

---

## Data Deletion

Users and server administrators can:

📧 Request deletion of stored data
📧 Contact the bot owner via Discord
📧 Use built-in deletion commands in the bot

---

- Regular security monitoring
- Routine security updates and patches
