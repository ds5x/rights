# Privacy Policy for Aegis System

**Last Updated:** June 22, 2026

Aegis System is a Discord moderation and security bot designed to help server administrators manage and protect their communities.

## Information We Collect

The bot may collect and store:

- Discord User IDs
- Discord Server (Guild) IDs
- Discord Channel IDs
- Moderation logs and security-related events
- Server configuration settings

## Purpose of Data Collection

This information is collected solely to:

- Provide moderation and security features
- Detect and prevent abuse
- Maintain server settings and configurations
- Generate moderation logs when enabled

## Data Sharing

The bot does not sell, rent, or share user data with third parties except where required by law.

## Data Retention

Data is retained only as long as necessary for the operation and security features of the bot.

## Data Deletion

Server owners or users may request deletion of stored data by contacting the bot owner.

## Security

Reasonable measures are taken to protect stored information from unauthorized access.

## Contact

For privacy-related questions or data deletion requests, please contact the bot owner through Discord.

By using this bot, you agree to this Privacy Policy.
